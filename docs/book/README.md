# 从零理解高性能 Kestrel 网络编程

这本书写给已经能读一点 C#，却还分不清端口、TCP 包、协议和缓冲区的读者。我们的目标不是记住几个“高性能 API”，而是让你能解释一段字节从设备到业务系统的全部旅程，能写出边界正确、资源有界、故障可诊断的网络程序，并知道每一个设计为什么存在。

原材料是上游 [KestrelApp 项目说明](https://github.com/xljiulang/KestrelApp/tree/ba06920608a416fd285c24538a87ad379c1bbd1b)、[原始文章](../1.1%20Kestrel简介.md)及仓库实际源码。本书按初学者的知识依赖重新组织，保留原作者用 Echo、Telnet、Redis、代理和传输包装教学的思路，逐项注明示例边界。源码学习基准是 `ba06920608a416fd285c24538a87ad379c1bbd1b`；对过时或过度概括的表述，按 API 契约修正，见[勘误与取舍](appendices/corrections.md)。

## 学完应能做什么

你应能独立完成以下事情，并向同事说明理由：

1. 画出 `Socket → IDuplexPipe → 连接中间件 → ConnectionHandler → 应用处理`，指出接收和发送的方向。
2. 给一个自定义协议写出字节级格式，处理不完整、多个合并、跨内存段、错误长度以及输入结束。
3. 解释 `Span`、`Memory`、`ReadOnlySequence` 和池化内存的所有权，避免归还后继续访问。
4. 正确配对 `ReadAsync / AdvanceTo`、`GetSpan / Advance / FlushAsync`，解释背压为什么可能造成等待甚至死锁。
5. 为协议处理名额、帧长、队列、等待时间和日志设置边界，说明监听器及部署层仍需限制的资源；用指标区分网络慢、业务慢、线程池堵塞和内存滞留。
6. 给出 ACK、重试、幂等和持久化的明确承诺，拒绝用“高性能”掩盖数据丢失。

## 一条贯穿全书的业务线

假设车间有一批温度和压力采集设备，每台每秒上报若干点位，网络偶尔抖动，中心数据库也可能维护。我们先在本机用模拟器接入一台设备，逐步讨论上千连接、慢消费者、设备重连、重复数据、证书和停机。

这里的规模和业务需求是**预设教学场景**，不代表仓库在某条产线验证过，也不是吞吐量承诺。实验不连接 PLC 或现场控制器。为避免泛泛而谈，我们定义 KG/1 二进制教学协议，并提供[可运行的网关与设备模拟器](../../samples/IndustrialGateway/README.md)。协议名称仅供本书使用，不是行业标准，也不等同于 OPC UA、Modbus 或 MQTT。

## 怎样阅读

全书有 21 章和 5 个附录，完整[目录在这里](../../SUMMARY.md)。每章按“遇到的问题 → 机制 → 为什么这样设计 → 源码 → 故障和练习”推进；练习答案在同章或[综合练习](part-4/20-exercises.md)，先做再看效果更好。

| 阶段 | 阅读范围 | 交付给自己的证据 |
|---|---|---|
| 认识网络 | 第 1—2 章 | 用纸画出客户端、端口、连接、消息 |
| 理解 Kestrel | 第 3—6 章 | 能走读 Echo/Telnet，说明两种中间件 |
| 掌握缓冲 | 第 7—12 章 | 正确解释内存借用、游标、背压和测量 |
| 理解架构 | 第 13—18 章 | 能从 Redis/代理案例解释工业网关取舍 |
| 独立实践 | 第 19—21 章 | 跑通实验、制造故障、完成毕业设计 |

如果你急着看到数据，先做[第 19 章的首次运行](part-4/19-lab.md)，再回到第 1 章。首次跑通不是掌握网络；遇到 EOF、队列或内存问题时，回到对应章节解释观测结果。

## 版本与可执行性

| 内容 | 版本 | 本书的用途 |
|---|---|---|
| 原 KestrelApp / Middleware / Framework | `net6.0` | 设计和源码导读，保留原状 |
| 原 Fiddler | `net7.0` | 代理/TLS 分层导读，保留原状 |
| 新 KG/1 网关与检查程序 | `net10.0` | 实际运行、故障注入、改造练习 |

.NET 6/7 已结束支持。不能因为装了更新 SDK，就认为旧框架运行时也已经安装。本次验证机器有 .NET SDK 10.0.403 与 11 RC，实验通过 [samples 内的 SDK 配置](../../samples/global.json)选择稳定 .NET 10；没有安装或改造旧运行时。新实验不引用旧项目、不修改旧解决方案，不依赖 Serilog、YARP 或额外 NuGet 包。

本书代码块会明确区分：**现有源码摘录**用于理解仓库；**说明片段/伪代码**需要结合上下文；**完整实验**以[实验目录](../../samples/IndustrialGateway/README.md)为准。不要把一段省略了清理或异常处理的解释代码直接当服务器部署。

## 书中三种承诺

- **仓库事实**：来自读过的源码，附具体文件链接，不把注释的意图自动当成正确实现。
- **实验事实**：来自可复现的检查；[验证记录](appendices/validation.md)说明覆盖范围及未覆盖部分。
- **生产建议**：在给定业务约束下的设计选择，附原因和失败代价；需要在你的设备、平台、证书体系和负载上重新验证。

书内 Mermaid 图只是帮助理解，文本也会说明同样的关系；阅读平台不渲染图时不影响完成练习。源码相对链接适合在工作区或 GitHub 阅读；导入 GitBook 时应保留整个仓库根为内容根，见[发布与维护](appendices/publishing.md)。
